# Open-Source Alternatives Suite

An open-source ecosystem of high-performance applications designed as free, community-driven alternatives to proprietary software from Adobe and Microsoft. Built to offer powerful creative, document, and productivity tools without subscription fees.

---

## 🎨 Adobe Alternatives

| Original Software | Open-Source Alternative | Description | Links |
| :--- | :--- | :--- | :--- |
| **Adobe Photoshop** | **PhotoCraft** | Advanced raster image editing, supporting layers, masks, filters, vector paths, and PSD files written in Rust. | [Website](https://getartcraft.com/apps/photocraft) \| [Source & Docs](https://github.com/artcraft/photocraft) |
| **Adobe Illustrator** | **VectorCraft** | Vector illustration tool built for high-performance vector graphics and scalable asset design. | [Website](https://getartcraft.com/apps/vectorcraft) \| [Source & Docs](https://github.com/artcraft/vectorcraft) |
| **Adobe Premiere Pro** | **FilmCraft** | Non-linear video editor with a high-performance GPU compositor, multi-track timeline, and native support for H.264, HEVC, ProRes, and AAC codecs. | [Website](https://getartcraft.com/apps/filmcraft) \| [Source & Docs](https://github.com/artcraft/filmcraft) |
| **Adobe After Effects** | **EffectCraft** | Motion graphics, visual effects, and animated titles creation using a layer-based composition system (solids, text, shapes). | [Website](https://getartcraft.com/apps/effectcraft) \| [Source & Docs](https://github.com/artcraft/effectcraft) |
| **Adobe Acrobat** | **PdfCraft / PrintCraft** | Complete PDF workbench for reading, organizing, merging, splitting, and securing PDF files with advanced layout capabilities. | [Website](https://getartcraft.com/apps/pdfcraft) \| [Source & Docs](https://github.com/artcraft/pdfcraft) |
| **Adobe InDesign** | **DesignCraft** | Page layout and desktop publishing software for creating books, magazines, and multi-page printable layouts. | [Website](https://getartcraft.com/apps/designcraft) \| [Source & Docs](https://github.com/artcraft/designcraft) |

## 📊 Microsoft Office Alternatives

| Original Software | Open-Source Alternative | Description | Links |
| :--- | :--- | :--- | :--- |
| **Microsoft Word** | **WordCraft** | Clean, open-source word processor written in Rust, supporting `.docx` documents, custom styles, tables, and mail merge. | [Website](https://getartcraft.com/apps/wordcraft) \| [Source & Docs](https://github.com/artcraft/wordcraft) |
| **Microsoft Excel** | **GridCraft** | Fast, open-source spreadsheet application built in Rust, featuring conditional formatting, complex formulas, and integrated charting. | [Website](https://getartcraft.com/apps/gridcraft) \| [Source & Docs](https://github.com/artcraft/gridcraft) |
| **Microsoft PowerPoint** | **DeckCraft** | Slide presentation application with native AI agent integration via CLI and Model Context Protocol (MCP), supporting layout customisation. | [Website](https://getartcraft.com/apps/deckcraft) \| [Source & Docs](https://github.com/artcraft/deckcraft) |

## 🤖 AI Agent Integration

Because all of these tools are open-source, you can connect AI agents directly to any of them using command-line interfaces (CLI) and Model Context Protocol (MCP) to automate workflows, build presentations, or process data programmatically.
